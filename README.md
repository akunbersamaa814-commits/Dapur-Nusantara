# Dapur Nusantara 🍛

Website kumpulan resep makanan khas Nusantara — tugas mata kuliah Pemrograman Web.

**Teknologi:** HTML · CSS · JavaScript · PHP

## Fitur
- Daftar resep dalam bentuk card
- Klik card → detail bahan & cara memasak (JavaScript)
- Pencarian resep berdasarkan nama/daerah/bahan (PHP)

## Menjalankan

```bash
php -S localhost:8000
```

Buka `http://localhost:8000`. Atau taruh folder ini di `htdocs` (XAMPP) / `htdocs` (MAMP) / `www` (Laragon).

Kalau perintah `php` belum dikenal tetapi MAMP sudah terpasang, pakai PHP bawaan MAMP:

```bash
/Applications/MAMP/bin/php/php8.5.12/bin/php -S localhost:8000
```
